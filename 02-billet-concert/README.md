# 02 — Billet de concert

**Notions :** chaînes, interpolation, concaténation, sprintf  
**Situation :** Un site prépare un billet lisible à partir de données brutes.

## Consignes

Construisez une ligne avec interpolation, une avec concaténation et un numéro à quatre chiffres avec `sprintf`. Le prix doit afficher deux décimales.

## Vérification

Le numéro 23 devient `0023` et le prix 35 devient `35.00`.

Depuis la racine du projet, lancez `php 02-billet-concert/index.php`. 

## Pourquoi cette solution

Les trois formes répondent à des besoins différents : insertion simple, assemblage explicite et format à largeur définie.

Une autre implémentation est recevable si elle respecte les consignes et les cas de vérification.
